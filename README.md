# limits-band

Полоса над полем ввода Claude Code: сколько израсходовано из лимитов подписки (5 часов и неделя), когда они сбросятся, сколько токенов занято и осталось в контексте и сколько токенов потрачено за сеанс.

Пример: `5 ч: 42% (сброс через 1 ч 10 мин) · Неделя: 18% (сброс через 3 д 5 ч) · Контекст: 76 тыс. из 200 тыс., осталось 124 тыс. · За сеанс: 1,3 млн токенов`

Лимиты подписки Anthropic сообщает только в процентах, поэтому для них показывается процент, а не токены.

- обновляется после каждого ответа Claude;
- при 90% пятичасового лимита показывает уведомление;
- кнопка «Скрыть» убирает полосу до конца сеанса.

## Установка

В Claude Code, в поле ввода:

```
/plugin install limits-band --marketplace kirsanovyamkino-commits/limits-band
```

На вопрос о добавлении источника ответьте `y`, затем выберите область установки (для себя — user).
